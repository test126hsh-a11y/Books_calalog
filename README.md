# Система управления книжным каталогом

**Практическая работа:** Веб-приложение для учета библиотечного фонда с функцией добавления новых книг, интерактивным редактированием записей и расширенной системой сортировки и фильтрации каталога.

Студент: **Муравьев Даниил**  
Персональная ветка: `Muravev`

---

## Реализованные требования (Моя зона ответственности)
* **CRUD-операции:** Модули добавления новых книг в систему и редактирования текущих метаданных.
* **Фильтрация:** Выпадающие списки для мгновенного отсеивания книг по авторам и жанрам, включая текстовое поле для ручного ввода кастомного жанра.
* **Сортировка:** Многокритериальная сортировка каталога по названию, автору, году, жанру и количеству экземпляров.
* **Макет:** Проектирование и верстка главной страницы приложения и структуры общей таблицы.

---

## Структура проекта
* `app.py` — backend на Python (Flask), бизнес-логика пагинации, сортировки, динамической фильтрации и сохранения/обновления данных [INDEX].
* `templates/` — HTML-шаблоны страниц (`base.html`, `index.html`, `menu.html`).
* `static/styles.css` — стилизация главной страницы, кастомных полей форм и интерфейса панели фильтров.
* `data/` — папка реляционной базы данных **SQLite3** для надежного хранения каталога.

## Этапы выполнения проекта по профессиональным ролям

### 1) Проектирование (Роль: Системный аналитик)
* **Входные данные:** Прием параметров `genre`, `author`, `year`, `sort` из адресной строки для фильтрации табличной выдачи каталога. Валидация полей форм добавления/изменения книги.
* **Выходные результаты:** Постраничный вывод каталога (пагинация), динамически формируемые списки уникальных авторов и жанров из БД, обновление записей в базе данных без дублирования строк.

### 2) Дизайн-макет (Роль: UI/UX Дизайнер)
* **Визуальные решения:** Разработка панели фильтров, расположенной в верхней части интерфейса для быстрого доступа. Оформление полей ввода форм с плавными рамками-подсветками при фокусе.
* **Интерактивные элементы:** Проектирование кнопки «Сбросить», очищающей только выбранные параметры фильтрации, без потери строки поиска. Создание скрытого поля «Свой жанр», плавно открывающегося только при выборе пункта «Другое...».

### 3) Разработка
* **Frontend-разработчик:** Сверстана главная страница каталога с широкой адаптивной таблицей на Grid/Flexbox. Настроен JavaScript-скрипт мгновенной отправки формы при изменении любого селектора фильтрации.
* **Backend-разработчик:** Написаны Flask-эндпоинты для обработки форм `POST /books/new` и `POST /books/<id>/edit`. Реализована сложная SQL-логика сборки динамического поискового запроса в зависимости от выбранных фильтров.
* **Интеграция:** Все фронтенд-компоненты бесшовно связаны с базой данных через шаблонизатор Jinja2.

### 4) Тестирование (Роль: QA-инженер)
* **Проверено:** Логика пагинации при одновременно активных фильтрах (параметры не теряются при переходе по страницам).
* **Проверено:** Корректность записи числовых полей (год издания, количество книг) и обработка исключений при отправке пустых форм добавления.
